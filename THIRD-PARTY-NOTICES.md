## Not included

**VB-Cable** (VB-Audio Virtual Cable) is donationware by VB-Audio Software (Vincent Burel) and is **not** redistributed
here. On first run MicMix downloads the official installer from https://vb-audio.com/Cable/, verifies its Authenticode
signature, and starts it so the user installs the driver themselves. Consider supporting VB-Audio if you use it.
